# PhysioCare AI - 核心視覺模型 (測試版)

這是我目前負責的 AI Model 部分，主要用 MediaPipe 做深蹲的姿態估計與角度計算

## 進度
目前已經完成：
- 即時攝像頭骨骼點追蹤（MediaPipe Pose）
- 計算左膝關節角度（髖-膝-踝）
- 判斷動作狀態：站直（STANDING）、半蹲（SQUATTING）、深蹲（DEEP SQUAT）
- 畫面顯示大字體角度與狀態
- 全屏顯示模式

## 環境配置
**非常重要：MediaPipe 必須是 0.10.21 版本，OpenCV 必須是 4.11.0 版本！** 

## 操作指南
- 站位要求：請距離鏡頭 2~3 公尺，確保全身（頭到腳踝）都在畫面裡
- 身體朝向：請側身面對鏡頭（左側朝向鏡頭），因為程式目前抓的是左腳的關鍵點。如果右側朝向鏡頭，左腳會被身體擋住，抓不到點
- 如何退出：按鍵盤上的 q 或 Esc 即可關閉視窗
- 如何全屏：按鍵盤上的 f 可以切換全屏模式，方便站遠一點看數字
- 動作測試：站直時角度應該接近 180 度，蹲下時角度會降到 90 度左右，可以觀察數字是否平滑變化
